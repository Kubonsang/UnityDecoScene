# Concept Room Starter

1. Create or select an existing room root.
2. Use **GameObject > Concept Room Decorator > Create Room Setup**.
3. Resize the authoring bounds to the room interior.
4. Assign the room's real floor collider to `ConceptRoom.floorColliders`.
5. Move the observation and keep-clear children to the entrance.
6. Create a brief, catalog, and composition plan from the Assets create menu.
7. Open **Window > Concept Room Decorator**.
